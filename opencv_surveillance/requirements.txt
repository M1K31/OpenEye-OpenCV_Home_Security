#     pip install -r requirements-object-detection.txt

# torch, torchvision and ultralytics are NOT listed here. They are the single
# largest thing this project could install, and most installations never enable
# object detection: ENABLE_OBJECT_DETECTION defaults to false and

# runs correctly without them.

# Measured on the Linux image before the split: 3.3 GB of wheels, of which about

# torch onto an arm64 image that will never see an NVIDIA GPU. The final image
